# Space Shooter Game (Python)

A small 2D arcade shooter built with Python's standard library (`tkinter`).

## Controls

* Left / Right arrows — move the ship
* Space — shoot
* P — pause / resume
* R — restart after game over

## Features

* Player movement, shooting, and collision detection
* Enemy spawning with increasing speed per level
* Score, lives, and level tracking
* Game over and restart screen

## Run

```bash
python space_shooter.py
```

## Requirements

Python 3.10+ with tkinter (included with most Python installs). No
external dependencies.
